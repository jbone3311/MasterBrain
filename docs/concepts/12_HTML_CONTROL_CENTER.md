# Owner control center

Status: exploratory rationale, captured 2026-10-15; no new implementation or
dependency decision. See the [concepts guide](README.md) for authority and provenance.

## Idea and lesson

An owner interface should make evidence, processing state and review choices understandable. HTML is a presentation choice, not a second knowledge database.

## Illustrative use

The owner can inspect a source quote before deciding on a proposal and see whether a document is pending, failed or ready.

## Boundaries and next evidence

Use current UI contracts for implemented screens. A dashboard sketch does not establish browser acceptance, hosted login, source writes or an autonomous assistant.
