# Invisible intelligence

Status: exploratory rationale, captured 2026-10-15; no new implementation or
dependency decision. See the [concepts guide](README.md) for authority and provenance.

## Idea and lesson

Make existing tools more useful without requiring every interaction to move into a new application. The SaneBox-inspired lesson from the owner discussion is a product hypothesis: familiar behavior can be an interface to intelligence. It is not a verified description of SaneBox or an integration commitment.

## Illustrative use

A fictional owner should be able to find the evidence behind a loan deadline while continuing to use their mail client. Quiet assistance still needs visible coverage, uncertainty and a way to correct mistakes.

## Boundaries and next evidence

Do not interpret silence as permission or a folder gesture as authorization for source effects. Validate the experience with fictional tasks before adopting a new interaction.
