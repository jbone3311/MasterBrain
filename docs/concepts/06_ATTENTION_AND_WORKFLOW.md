# Attention and workflow

Status: exploratory rationale, captured 2026-10-15; no new implementation or
dependency decision. See the [concepts guide](README.md) for authority and provenance.

## Idea and lesson

Help an owner decide what needs attention using evidence, deadlines and explicit preferences. Priority is an interpretation that should be explainable.

## Illustrative use

A source-stated due date can support a review item; an inferred urgency score should remain distinguishable from that date.

## Boundaries and next evidence

Suppressing reminders or executing work can hide important obligations. Define missed-event recovery, cancellation and approval before changing workflow behavior.
